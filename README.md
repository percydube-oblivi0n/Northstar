# Northstar | SaaS Landing Page

A responsive landing page concept for **Northstar**, a fictional project management platform designed to help teams organise tasks, track progress, and keep projects moving.

This project was created as a web design and front-end development portfolio piece. The design was developed with Figma Make and adapted into plain HTML, CSS, and JavaScript.

## Features

- Responsive landing page layout for desktop and mobile screens
- SaaS-style hero section and dashboard preview
- Feature cards and product showcase
- Illustrative pricing section
- FAQ section using native HTML `<details>` and `<summary>` elements
- Mobile navigation menu with JavaScript
- Semantic HTML and basic accessibility attributes
- No framework or build step required

## Built With

- **HTML5** for page structure
- **CSS3** for styling, layout, and responsive design
- **Vanilla JavaScript** for mobile navigation interactions
- **Google Fonts** for typography
- **Figma Make** for AI-assisted design generation

## Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.

No Node.js, package installation, or build tools are required. An internet connection is needed to load the Google Fonts; the page does not depend on external image assets.

## Demo Limitations

Northstar is a **fictional front-end portfolio concept**, not a functioning project management service.

- Sign-in and sign-up are not connected to authentication.
- Pricing and call-to-action buttons are illustrative and do not process payments.
- The dashboard is a visual mockup and does not store or manage real projects.
- Contact details, privacy policy, and terms links are placeholders for demonstration purposes.
- No customer data is collected or processed by this static page.
