NORTHSTAR LANDING PAGE
======================

Files
- index.html: page structure and content
- style.css: layout, typography, responsive styles, and visual design
- script.js: mobile navigation interactions

How to run
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Internet access is needed for the Google Fonts import. The page itself uses no external image assets.

Important notes
- This is a static frontend portfolio concept for a fictional SaaS product.
- Sign-in, signup, pricing, and contact links are illustrative and do not process real data or payments.
- FAQ items use native HTML details/summary elements.
- No React, TypeScript, Tailwind, build tools, or package installation is required.
- Test desktop and mobile sizes before publishing the project.
